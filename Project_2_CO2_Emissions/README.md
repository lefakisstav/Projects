# Project_CO2_Emissions_Analysis

This project focuses on analyzing global Carbon Dioxide (CO₂) emissions using Microsoft Power BI. The goal is to transform raw emissions data into meaningful insights through interactive visualizations and dashboards.

The analysis explores global emission trends, compares countries' contributions, identifies major CO₂ emitters, and tracks changes in emissions over time.

The main objectives of this project are:

- Analyze CO₂ emissions trends over years 2013-2022.
- Compare emissions between different countries.
- Identify countries with the highest carbon emissions.
- Visualize changes in emissions over time.
- Explore relationships between countries and emission levels.
- Provide an interactive dashboard for sustainability analysis.
